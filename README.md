# Contextuality under characterized loss

Reproducibility materials for the manuscript:

> Arash Esmaili Zaghi, Ofer Harel, and Kun Chen, “Contextuality under characterized loss: quantifying missing contextual information via channel-transported relative entropy,” *New Journal of Physics*.

The repository preserves the two supplementary archives associated with the manuscript. All numerical examples and benchmark distributions are synthetic; the archives contain no proprietary or human-subject data.

## Supplementary archives

- `fmci_operational_bundle.zip` — operational, sensitivity, and finite-sample code, documentation, tests, synthetic examples, machine-readable outputs, figures, and checksum manifests.
- `fmci_benchmarks_bundle.zip` — benchmark code, configurations, precomputed outputs, validation records, figures, tests, and checksum manifests.

The archives are kept intact so that the public files match the manuscript’s supplementary materials. Each archive includes its own README and integrity manifests.

## Use

Extract the relevant archive and follow its internal README. The operational archive is the primary package for the operational, sensitivity, and finite-sample analyses; the benchmark archive preserves the benchmark outputs and validation records used for the manuscript’s computational results.
